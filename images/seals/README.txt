SEAL FOLDER / ទីតាំងរូបត្រាមាស  —  images/seals/
=====================================================
ឯកសារដែលកូដរង់ចាំ / file names the code expects:
  seal1.webp (ឈូក)  seal2.webp (LT Media)  seal3.webp (ចិញ្ចៀន)
  seal4.webp (បេះដូង)  seal5.webp (ក្បាច់)  seal6.webp (ស្លឹកឈើ)

បន្ថែមត្រាថ្មី / add a new seal:
  1) ដាក់ឯកសារក្នុង folder នេះ (WebP/PNG ថ្លា ការ៉េ) / put the file here (transparent, square)
  2) បន្ថែមមួយបន្ទាត់ក្នុង SEAL_BUTTONS (wib-data.js) / add one line in SEAL_BUTTONS:
     seal7:{ label:"ត្រា ៧", file:"seal7.webp", size:96 },
  ប្រយ័ត្នអក្សរធំ/តូច — GitHub Pages ញែកអក្សរធំតូច / file names are case-sensitive.
